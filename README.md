# QA Automation Project

## Project Overview

This project is a Selenium WebDriver automation framework developed using Java, TestNG, Maven, and Page Object Model (POM).

The project automates the SauceDemo e-commerce website and validates the complete shopping and checkout flow.

## Application Under Test

https://www.saucedemo.com/

## Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- IntelliJ IDEA
- Git & GitHub

## Test Scenarios

The automation suite covers:

- User Login
- Product Selection
- Add Product to Cart
- Cart Verification
- Checkout Details
- Order Completion
- Order Confirmation
